# Deliverable 1: separate documents

The three parts of the selected Deliverable 1 are now available as independent files:

| Document | Contents |
| --- | --- |
| [Software Requirements Specification](SRS.md) | Part A: 11 functional, 4 non-functional, and 4 security requirements; use-case diagram |
| [Test Plan and Test Cases](Test_Cases.md) | Part B: test approach, TC-01 to TC-12, expected and actual results, status, requirement traceability |
| [Software Architecture and Design Specification](SAD.md) | Part C: layered architecture, data design, security, interfaces, component and sequence diagrams |

The SRS and SAD preserve the original version 1.0, dated 28 September 2026. The current test-case page adds recorded actual results and PASS statuses beside the original expectations. Requirement/test IDs and the four original diagrams are retained.
