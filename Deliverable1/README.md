# Deliverable 1: separate documents

The three parts of the selected Deliverable 1 are now available as independent files:

| Document | Contents |
| --- | --- |
| [Software Requirements Specification](SRS.md) | Part A: 19 role-based user stories with technical acceptance criteria; use-case diagram |
| [Test Plan and Test Cases](Test_Cases.md) | Part B: test approach, TC-01 to TC-12, expected and actual results, status, requirement traceability |
| [Software Architecture and Design Specification](SAD.md) | Part C: layered architecture, data design, security, interfaces, component and sequence diagrams |

The [original SRS version 1.0](SRS_v1_Baseline.md) and the SAD preserve the source baseline dated 28 September 2026. The current SRS and atomic revision express requirements as learner, administrator, or user stories while retaining the technical acceptance criteria. The current test-case page adds recorded actual results and PASS statuses beside the original expectations. The [before-testing plan](Test_Plan_v1_Before.md) retains the expected-only version, and the [original combined Word document](Deliverable%201.docx) remains the source record. Requirement/test IDs and the four original diagrams are retained.

Evaluation revisions prepared on 17 November 2026: [atomic SRS revision](SRS_Atomic_Revision.md), [before-testing plan](Test_Plan_v1_Before.md), [after-testing plan with actual results](Test_Plan_v2_After.md), and [web architecture addendum](SAD_Web_Addendum.md). The original baseline remains intact. [Generated reports](../docs/reports/README.md) distinguish actual execution, measured coverage and remaining limitations.

The later Iteration 3 browser application extends that baseline. Its current implementation, storage, security, demo accounts, and verification commands are documented in [web/README.md](../web/README.md). The [presentation guide](../docs/presentation-guide.md) explains the iteration progression and the current website demo.
